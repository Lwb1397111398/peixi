## 未完成项与下一步

- **待推送后观察**：CI 首跑是否全绿（windows-latest 上 ffmpeg-kit/libmpv/ANGLE 直连预取是主要不确定点，fetch 脚本已按 `CI=true` 分流直连）；`latest` Release 元数据是否可匿名 GET。
- 老版本（无更新逻辑的现装版）→ 新版的首次升级走不通 App 内更新（死锁），首装需手动覆盖一次；之后全自动。
- Android 端未接入 App 内更新（`applyUpdate` 仅 Windows；产品定位即 Windows 使用，需要时再扩展）。
- 后续每次改完代码 push main 即自动发版，无需手动构建传文件。

## 已否决的方案

- 私有仓库 + PAT 令牌方案：用户明确要公开仓库免令牌（公开后镜像兜底才可用，私有资产镜像代理不了）。
