# 当前进度

> 最后更新：2026-10-25（会话：LLM 渠道去默认百炼 + 语音识别收敛为纯本地）

## 当前目标与范围

- 目标：LLM 页面去默认化——去掉内置的阿里云百炼默认渠道/默认模型，全部改为用户自定义渠道，轻量/主力/视觉各角色独立绑定；同时下线语音识别的云端中转（DashScope 录音文件识别 + OSS 中转桶），只保留本地 sherpa-onnx 离线识别（老板原话：中转成本高、根本不会用）。

## 已验证结果（有证据）

- `flutter analyze` 零问题；`flutter test` **364 个用例全过**（较改动前净减 12：删除云端 ASR/OSS 客户端与迁移相关用例，新增路由零回落、轻量→主力降级、本地管线取消/补转 wav 等用例）。
- 渠道化已无任何百炼痕迹：`RoutingTable.resolve` 只认显式绑定（未绑定返回 null），`fallbackModelFor`/`_firstUsable`/旧单配置首启迁移（`llm.base_url` 等）全部删除；设置页不再出现「默认渠道」。
- 语音识别收敛为本地单模式：`AsrClient`（DashScope 提交/轮询）、`oss_client.dart`、`OssConfig`、`AsrMode` 全删；管线固定产 16k wav 直接识别；处理页时间线无上传阶段；设置页 OSS 区块与 ASR 模式下拉移除，只留本地模型状态与下载入口。
- 云端时代残留数据的兼容路径有测试覆盖：UPLOADED 状态项目重试 → mp3 缓存补转 wav 识别；failed_stage='upload' 旧项目重试落回 imported 兜底。
- 轻量槽位未绑定时服务层自动降级用主力槽位（地图/摘要/角色映射/摘要更新不再静默跳过）——此回归在 commentary 冒烟测试中暴露并修复，配套新增单测锁定。

## 已否决的方案

- 保留「未绑定槽位回落首个可用渠道 + qwen-* 默认模型名」：会把请求静默打到任意渠道的错误模型上，违背「角色分明、自定义优先」。
- 轻量槽位未绑定就静默跳过摘要/映射调用：会让解说质量悄悄退化（冒烟测试实测 questions 掉一半），改为降级主力槽位。
- 保留 OSS 供未来备份用：当前项目包导出是本地 zip，OSS 唯一用途就是 ASR 中转，整体下线，将来要用再加。
