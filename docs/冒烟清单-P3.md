# P3 手动冒烟清单（Windows 真机）

单元/Widget 测试无法覆盖的真机行为，逐项人工确认。运行 `flutter run -d windows` 后执行。

## A. 批量导入与串行队列
- [ ] 「导入视频」多选一整季（≥3 集）：全部入库，标题带"第 N 集"；库页 SnackBar 提示"已开始处理 N 集"
- [ ] 观察处理：同一时刻只有一集在抽取音频/识别（其余排队），队列逐个推进
- [ ] 排队中点某集的 ×（取消）：该集直接出队不处理；正在处理的一集协作式中断并保留进度
- [ ] 单个损坏文件混在批次中：弹窗列出该文件失败原因，其余正常入库
- [ ] 未配置 API Key 时批量导入：直接提示先去设置，不弹文件选择器后的静默失败
- [ ] 拖拽小说/epub：正常入库排队

## B. LLM 预算与缓存
- [ ] 设置页填"月度 token 预算"（如 50000）保存；把预算调到小于本月已用，再跑解说 → 处理页失败原因显示"本月 LLM token 预算已用尽（已用 X / 上限 Y）"
- [ ] 清空预算（留空）保存后重试，恢复正常
- [ ] 同一项目解说阶段失败后重试：token 消耗不再为已成功场景重复计费（响应缓存）
- [ ] 设置页「清空调用统计与响应缓存」：确认后统计归零
- [ ] （观察）连续两次"测试连接"之外的重复管线调用：第二次不再等网络

## C. 卡片 / SRS / Anki 导出
- [ ] 卡片集标题显示"卡片集（N）· 到期 M"
- [ ] 点开任意卡片：改解释保存 → 列表即时刷新（无需重进页面）
- [ ] 把词条改成同项目已有词条：SnackBar 提示失败，原词条不变
- [ ] 删除卡片：确认后从列表消失
- [ ] 「复习」进入会话：翻面 → 四键评分（按钮上显示下次间隔预览）→ 全部评完显示"已复习 N 张"
- [ ] 「忘了」的卡片 10 分钟后重新出现在到期数里
- [ ] 「导出 Anki CSV」选目录保存：文件用 Anki 导入向导可识别（front/back/tags 三列）

## D. 桌面端体验
- [ ] 关闭窗口前挪动/缩放窗口 → 重新启动：窗口恢复上次尺寸与位置
- [ ] 窗口最小缩放到 900×560 以下被限制
- [ ] 把一个 mkv 拖到媒体库：出现"松手导入"遮罩，松手后进入视频管线
- [ ] 把 txt 和 zip 一起拖入：分别按小说与项目包导入；拖入无关文件（如 .md）提示"无法识别"
- [ ] 播放器内：空格暂停/继续；←/→ 快退/快进 10 秒且进度条正确；↑/↓ 调音量
- [ ] 弹题输入框获得焦点时按空格：输入空格而不是切换播放
- [ ] 卡片右键：弹出与长按相同的操作菜单（导出项目包/删除）

## E. 内嵌字幕
- [ ] 导入带文字字幕流（srt/ass）的视频，处理后进播放器：字幕默认显示，AppBar 字幕按钮可关/开
- [ ] 解说与卡片文本与片内字幕一致（错别字以字幕为准被纠正）
- [ ] 导入无字幕流的视频：播放器无字幕按钮，管线正常不受影响
- [ ] （PGS/图形字幕视频）提取失败被跳过，不阻塞管线

## F. 项目包导出/导入
- [ ] 导出一个 2 小时电影的项目包：观察任务管理器内存无数百 MB 峰值；桌面端改为"选择导出位置"目录选择器
- [ ] 导入该项目包：解说/卡片/问答/音频全部还原，播放页提示视频缺失
- [ ] 旧版本（P3 之前导出）的 .peixi.zip 仍可导入，卡片复习状态为默认（新卡）
