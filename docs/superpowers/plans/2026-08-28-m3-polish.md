**Files:** `lib/features/backup/project_package.dart`（新）、library_page 长按菜单改造

- 导入：解包→按依赖序插入（projects 新 id→characters→segments/scenes→commentaries→cards/questions→qa_records→chapters/paragraphs→annotations），全部 FK 重映射；音频解到 audioDir。视频项目不含视频本体（体积原因，交付说明注明：导入后可看解说/问答，重播需重新导入视频文件——metaJson 标 `mediaMissing:true`，媒体库卡片提示）。
- UI：卡片长按 → 底部弹层〔导出项目包〕〔删除〕；媒体库 AppBar 导入按钮（file_picker .peixi/.zip）。
- 测试：novel 项目 roundtrip（导出→清库→导入→行数与内容全等）；id 重映射正确；音频文件还原。

### Task C5: EPUB 导入（M3）
**Files:** `lib/core/novel/epub_parser.dart`（新）
- 依赖偏离：epubx 与 media_kit 的 image 3/4 冲突无法共存 → 内置轻量解析器（archive+xml，纯 Dart）。
- 实现：container.xml→OPF→spine 顺序→每章 XHTML 剥标签+实体解码→NovelDoc（章标题取 <title> 或 TOC）；仅支持文本型 EPUB（无 DRM）。
- `importNovel()` 扩展接受 .epub（按扩展名分派 parser）。
- 测试：程序化构造最小 EPUB（zip+opf+html）→ 章节切分、实体解码、段落提取。

### Task C6: 实验性视觉辅助（M3，experimental）
**Files:** `lib/core/media/ffmpeg_service.dart`（加 extractKeyframe）、`lib/core/llm/llm_service.dart`（加 chatRaw 多模态）、`lib/features/calibration/visual_assistant.dart`（新）、calibration_page 加按钮
- 流程：每个声音簇取代表台词时间点 → ffmpeg 抽 1 帧 jpg → base64 → qwen-vl（chatRaw，image_url data URI）问"画面中说话的人是谁/外观" → 与簇名候选合并展示。
- 校准页每簇行加〔视觉辅助〕按钮；结果填入建议名（用户可改，最终仍以确认动作为准）。实验性：失败静默降级（toast 提示）。
- 测试：帧时间点选择、prompt 构造、响应解析（fake adapter）；ffmpeg 抽帧用 fake。

## 关键决策记录
1. epubx 依赖冲突 → archive+xml 自实现（功能等效子集：文本型 EPUB）。
2. 项目包用 zip（设计稿 8.6 明确 zip）；novel 完全可迁移；video 只带音频与解说数据，视频本体不打包。
3. 复盘"连续答题天数"按本地自然日计算（answeredAt）。
4. 视觉辅助仅作为校准建议来源之一，不自动改名（实验性、可关闭）。
