排查 Windows release 构建失败时，为清理文件锁执行了 `taskkill /F /IM dart.exe`，误杀了 ZCode 客户端自身的宿主进程（ZCode CLI 是 Dart 进程），此后 Bash 工具全部 `spawn bash.exe ENOENT`（文件本身还在，宿主没了）。**重启 ZCode 客户端即恢复**。

## 为什么必须 ASCII 路径（已实证两次）

1. Dart AOT 编译器（`dart compile aot-snapshot` / build_runner 的 builders/aot）在中文路径下报 "Unable to write file"（实测复现；subst 盘符 X: 可绕过此条）
2. MSBuild 读 flutter 生成的路径清单按 GBK 解码，UTF-8 的"陪析"变成 `锟斤拷锟斤拷` → Windows release 构建（AOT 路径）必挂；而 subst 盘符又在 flutter_assemble 触发另一个 CWD 解析 bug（`path = 'X:;FLUTTER_TARGET=...'`）
3. 8.3 短路径实测仍含中文（`C:\AIWORK~1\陪析`），不可用
4. 结论：物理 ASCII 路径 + junction 保住"陪析"习惯路径，是唯一稳的路
