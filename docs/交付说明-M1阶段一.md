## 二、目录迁移：陪析 → peixi（重要）

原目录 `C:\AI WorkSpace\陪析` 的中文路径会导致两类构建故障：
- dart AOT / build_runner 无法写 `.dart_tool/build/`（符号链接与路径编码问题）
- MSBuild 以 GBK 读取路径产生"锟斤拷"乱码，Windows release 必挂

因此项目物理目录已迁移为全 ASCII 的 `C:\AI WorkSpace\peixi`（git 记录为 69 个文件 rename，100% 相似）。迁移后 build_runner、analyze、test、双端 release/debug 构建全部验证通过。

**遗留**：旧的空目录 `C:\AI WorkSpace\陪析` 因被当前 ZCode 会话的工作目录句柄锁定无法删除。下次以其他目录为工作目录重启 ZCode 后可删除该空目录；如仍习惯用 `陪析` 路径访问，可建 junction：`mklink /J "C:\AI WorkSpace\陪析" "C:\AI WorkSpace\peixi"`（管理员）。

## 三、Android 构建注意事项（sqlite3 预编译库）

`sqlite3` 包通过 native assets 钩子在构建时从 GitHub Releases 下载 `libsqlite3.<abi>.android.so`，本机访问 GitHub 间歇性超时会导致 `Target build_hooks failed`。

解决方案：已校验的 4 个 ABI 库固化在 `tool/sqlite3-android-cache/`，脚本 `tool/install-sqlite3-android.sh` 将其装入钩子缓存。**每次 `flutter clean` 之后（缓存被删）、构建 Android 之前，需重跑一次**：

```bash
bash tool/install-sqlite3-android.sh
```

（Windows 端的 sqlite3.dll 体积小、下载稳定，未做同样处理；若也失败可参照脚本思路。）
